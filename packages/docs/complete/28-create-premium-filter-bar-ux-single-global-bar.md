# Story 28: Create Premium Filter Bar UX (Single Global Bar)

## Story Metadata
- Created Date: 2026-02-16
- Status: `complete`
- Completed Date: `2026-02-16`

## Goal
Design and implement a premium single filter bar that feels best-in-class for restaurant analytics.

## Why This Matters
- A single global control center reduces confusion and speeds decision-making.
- High-class UX increases confidence in data-driven actions.

## Scope
- Build one top filter bar for search, chips, ranges, sort, and reset.
- Use business-first copy and control labels.
- Optimize for both desktop and mobile.

## UX Requirements
- Clear visual hierarchy and compact information density.
- High discoverability of key controls.
- Strong interaction feedback for applied filters.

## Acceptance Criteria
- Filter bar is responsive, accessible, and keyboard-usable.
- Applied filters are visible and removable individually.
- Reset behavior is predictable and restores defaults.

## Deliverables
- `MatrixFilterBar` component.
- Responsive layout + interaction states.
