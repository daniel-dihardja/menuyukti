# Story 09: Create Business Marts

## Goal
Expose stable, marketer-friendly analytical outputs without direct dependence on raw warehouse complexity.

## Scope
- Build marts:
  - `marts.mart_menu_performance`
  - `marts.mart_daypart_behavior`
  - `marts.mart_profitability_mix`
  - `marts.mart_agent_marketing_signals` (if applicable)
- Define field-level semantic descriptions.

## Acceptance Criteria
- Dashboards/consumers can use marts without custom joins.
- Mart definitions are versioned and documented.
- Mart outputs are traceable to source facts via lineage metadata.

## Deliverables
- Mart models/tables.
- Mart dictionary doc.
