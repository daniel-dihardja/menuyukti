## Naming and Location Rules
- Open epic path: `docs/planning/todo/epic-<topic>.md`
- Closed epic path: `docs/planning/archive/<EPIC_ID>/epic-<topic>.md`
- Archive folder id format: `EPIC-<DOMAIN>-<TOPIC>`
