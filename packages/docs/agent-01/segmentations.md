## The Correct Hierarchy (MenuYukti Style)

### Layer 1 — Deterministic Segmentation _(Mandatory)_

Define segments using **explicit, rule-based logic**.

---

### Common, Safe Dimensions

#### 🕒 Time-Based

- **Breakfast** (e.g. 06:00–10:30)
- **Lunch** (11:00–14:30)
- **Afternoon** (14:30–17:00)
- **Dinner** (17:00–22:00)
- **Late Night** (22:00+)

#### 📅 Day-Based

- **Weekday**
- **Weekend**
- **Specific weekdays** (Mon–Sun)

#### 🛍 Order Type _(if available)_

- **Dine-in**
- **Takeaway**
- **Delivery**

#### 👥 Order Size

- **Single**
- **Couple**
- **Group**

---

### Properties of Layer 1 Segments

All segments in this layer are:

- **Explainable**
- **Configurable**
- **Unit-testable**
- **Stable over time**
