# Story 11: Dual-Run and Reconciliation

## Goal
Validate new warehouse outputs against legacy snapshot outputs before cutover.

## Scope
- Run old and new pipelines in parallel for a defined window.
- Reconcile key KPIs by location and period.
- Define acceptable variance thresholds.

## Acceptance Criteria
- Automated parity report exists per run.
- KPI variance remains within agreed thresholds.
- Any divergence has categorized root-cause logs.

## Deliverables
- Reconciliation job + report artifact.
- Variance threshold policy doc.
