# Story 77: Add Scheduler Help Tooltips

## Story Metadata
- Created Date: 2026-02-17
- Status: `todo`
- Parent: none

## Goal
Improve scheduler usability by adding contextual help tooltips for key controls and fields.

## Why This Matters
- Scheduler has many decision fields and trust indicators that can be misinterpreted without inline guidance.
- Tooltips reduce onboarding time and improve decision consistency for marketers and analysts.

## Scope
- Add in-context help tooltips on core scheduler controls and field labels.
- Explain trust/readiness states and confidence usage directly in UI.
- Add practical hints for campaign/post IDs, schedule status, and rationale fields.

## Acceptance Criteria
- Users can access short explanatory tooltips on primary scheduler inputs.
- Tooltip copy clarifies meaning, not implementation details.
- Tooltip interactions are keyboard accessible and do not break existing workflows.

## Deliverables
- Scheduler UI updates with tooltip triggers and concise help content.
- Any required localization or text updates for new tooltip labels.
