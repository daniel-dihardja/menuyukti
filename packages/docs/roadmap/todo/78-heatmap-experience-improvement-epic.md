# Story 78: Heatmap Experience Improvement Epic

## Story Metadata
- Created Date: 2026-02-17
- Status: `todo`
- Parent: none

## Goal
Upgrade the heatmap page from a raw visualization into a decision-grade experience that delivers clear value for restaurant marketers and menu analysts.

## Why This Matters
- Current heatmap view is functional but mostly descriptive; users must manually infer actions.
- Marketers need campaign timing guidance, while analysts need operational and profitability context.
- Trust/readiness signals should be visible on all decision pages, including heatmaps.

## Scope
- Add decision-focused insights and guided actions for both personas.
- Add filtering, segmentation, and explainability that reduce manual interpretation effort.
- Add trust/readiness and confidence behaviors aligned with existing policy.
- Add export, testing, and documentation updates for production readiness.

## Acceptance Criteria
- Heatmap page clearly supports marketer timing decisions and analyst optimization decisions.
- Trust/readiness context is visible and impacts confidence messaging.
- Release-quality coverage includes tests and updated manual guidance.
